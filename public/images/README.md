# 📸 Pasta de Imagens - Logo RoboticsBr

## ⚠️ IMPORTANTE

Coloque a imagem do logo da RoboticsBr nesta pasta (`public/images/`) com um dos seguintes nomes:

### Nomes aceitos (o componente tentará encontrar automaticamente):
- `logo-roboticsbr.png` (recomendado)
- `logo-roboticsbr.jpg`
- `logo-roboticsbr.jpeg`
- `logo-roboticsbr.webp`
- `logo.png`
- `logo.jpg`
- `roboticsbr-logo.png`
- `roboticsbr-logo.jpg`

## 📍 Localização

A imagem deve estar em:
```
public/images/logo-roboticsbr.png
```

## ✅ Como verificar

1. Adicione a imagem na pasta `public/images/`
2. Reinicie o servidor de desenvolvimento (`npm run dev`)
3. A imagem aparecerá automaticamente no navbar e footer

## 🔍 Se a imagem não aparecer

- Verifique se o nome do arquivo está correto
- Verifique se a imagem está na pasta `public/images/` (não em `assets/`)
- Verifique o console do navegador para mensagens de erro
- Certifique-se de que o servidor foi reiniciado após adicionar a imagem
